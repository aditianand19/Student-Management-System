# Student Management System

A web-based Student Management System developed using Java and Spring Boot. This application helps manage student records efficiently through a simple and user-friendly interface.

## Live Demo

**Live Website:** https://student-management-system-aditi.onrender.com/

## Features

- Add new student records
- View all student records
- Edit existing student details
- Delete student records
- Database integration
- User-friendly web interface
- Cloud deployment

## Technologies Used

- **Programming Language:** Java
- **Backend Framework:** Spring Boot
- **Web Framework:** Spring MVC
- **ORM:** Hibernate
- **Data Access:** Spring Data JPA
- **Frontend:** HTML, CSS, Thymeleaf
- **Database:** TiDB Cloud (MySQL Compatible)
- **Build Tool:** Maven
- **IDE:** IntelliJ IDEA
- **Deployment Platform:** Render
- **Version Control:** Git and GitHub

## Project Architecture

The application follows a layered architecture:

- **Controller Layer:** Handles HTTP requests.
- **Service Layer:** Contains business logic.
- **Repository Layer:** Handles database operations.
- **Entity Layer:** Represents student data.
- **View Layer:** Displays the application interface using Thymeleaf.
